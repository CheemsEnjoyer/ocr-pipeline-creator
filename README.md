# OCR Flow Studio

Интерактивный React-интерфейс для сборки OCR-пайплайнов из этапов: загрузка, OCR, извлечение текста, LLM-анализ и вывод результата.

## Локальный запуск

```bash
npm install
npm run dev
```

Приложение откроется на `http://localhost:5173`.

## PostgreSQL

Схема находится в `database/schema.sql`. Она содержит типы документов, пайплайны, шаги, извлекаемые поля, файлы и историю запусков.

```bash
createdb ocr_flow
psql ocr_flow < database/schema.sql
```

Скопируйте `.env.example` в `.env` и задайте `DATABASE_URL`. В production рекомендуется держать загрузки в S3-совместимом object storage, а в PostgreSQL — метаданные, структуру пайплайна и результаты.

## Архитектура обработки

1. `start` принимает файл и определяет его тип.
2. Изображения и сканы идут в `ocr`; цифровые PDF/DOCX — в `extract`.
3. Нормализованный текст передаётся в `llm` с промптом и JSON-схемой параметров.
4. `output` сохраняет результат и отдаёт JSON, CSV или вызывает webhook.

Сейчас интерфейс работает как функциональный прототип: загрузка, настройка блоков, создание типов документов, редактирование параметров и тестовый запуск доступны в браузере. Для реальной обработки подключите API-сервис к переменным из `.env.example`.
