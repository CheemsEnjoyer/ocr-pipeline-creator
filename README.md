# OCR Flow Studio

Интерактивный React-интерфейс для сборки произвольных OCR-пайплайнов: узлы можно добавлять в любом количестве, перетаскивать по свободному холсту и соединять с ветвлениями.

## Локальный запуск

```bash
npm install
npm run dev
```

Приложение откроется на `http://localhost:5173`.

## PostgreSQL

Схема находится в `database/schema.sql`. Она содержит типы документов, пайплайны, шаги, извлекаемые поля, файлы и историю запусков.

```bash
createdb ocr_flow
psql ocr_flow < database/schema.sql
```

Скопируйте `.env.example` в `.env` и задайте `DATABASE_URL`. В production рекомендуется держать загрузки в S3-совместимом object storage, а в PostgreSQL — метаданные, структуру пайплайна и результаты.

## Архитектура обработки

Каждый пайплайн хранит собственный набор узлов, координаты и связи. Один тип узла можно использовать многократно, а граф может ветвиться. LLM-узлы независимо выбирают модель LiteLLM, промпт и схему результата. Список моделей загружается из `GET /v1/models`, выполнение идёт через `POST /v1/chat/completions`.

Для LLM настройте `LITELLM_BASE_URL` и `LITELLM_API_KEY` из `.env.example`. Ключ остаётся на сервере и не передаётся в браузер.
